# 처리량과 운영비 산정

2026-10-24 기준의 계획용 산식입니다. 부하 시험이나 실제 청구 결과가 아닙니다. 가격은 USD, 세금·환율은 제외합니다. 기존 계정의 무료 포함량을 다른 서비스가 이미 사용했을 수 있으므로 별도 확인해야 합니다.

## 입력 가정

운전자 한 명이 매일 1시간, 30일 사용하고, GPS는 5초마다 측정, 업로드는 30초마다 합니다. '하루 이용 운전자 수'와 '동시에 주행하는 운전자 수'는 구분합니다.

```text
월 관측 점 수 = 일 운전자 수 × 3,600 / 5 × 30
월 업로드 수 = 일 운전자 수 × 3,600 / 30 × 30
최대 초당 업로드 수 = 동시에 주행하는 운전자 수 / 30
큐 연산 수 = 업로드 수 × 3  (한 배치를 한 메시지에 담고, 64KB 미만, 재시도 없음)
```

| 하루 운전자 | 월 GPS 점 | 월 업로드 | 전원이 동시 주행 시 요청/초 | 기본 큐 연산/월 |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 2,160,000 | 360,000 | 3.33 | 1,080,000 |
| 1,000 | 21,600,000 | 3,600,000 | 33.33 | 10,800,000 |
| 10,000 | 216,000,000 | 36,000,000 | 333.33 | 108,000,000 |

평균 요청 수가 작아도 매 30초에 동기화된 업로드가 몰리면 순간 부하가 큽니다. 클라이언트 업로드에 작은 무작위 지연을 주고 동기화된 최악 조건도 시험합니다.

## 큐 비용만 계산한 예

현재 Paid 기준 큐는 월 100만 연산 포함 후 100만 연산당 $0.40입니다. 메시지는 64KB 단위로 계산하고 일반적으로 쓰기·읽기·삭제 3연산을 사용합니다. 여러 메시지를 한 API 호출로 보내는 것과 여러 관측을 한 메시지에 넣는 것은 다릅니다. [공식 가격](https://developers.cloudflare.com/queues/platform/pricing/)

| 하루 운전자 | 위 가정의 큐 비용/월 |
| ---: | ---: |
| 100 | $0.032 |
| 1,000 | $3.92 |
| 10,000 | $42.80 |

이 금액은 **총비용이 아닙니다.** Worker 기본 요금·CPU, Durable Objects 연산/활성시간/저장, 도로 매칭·경로 계산 서버, 지도 빌드, 데이터베이스, 파일 저장과 읽기·쓰기, 관측 도구가 빠져 있습니다. 재시도와 실패 보관 큐도 추가됩니다.

## 계산 비용과 저장 비용

하루 운전자 1,000명 시 월 360만 배치를 모두 서버에서 지도 매칭한다고 가정합니다. 배치당 순수 CPU가 20ms이면 약 20 CPU시간, 100ms이면 약 100 CPU시간입니다. 두 수치는 가상 입력입니다. 매칭 문맥 길이, 도시 밀도, 병렬 처리 효율, 상시 메모리 비용은 이 산식에 포함되지 않습니다.

```text
월 매칭 CPU시간 = 월 배치 수 × 배치당 CPU초 / 3,600
순간 필요 코어 ≈ 최대 요청/초 × 배치당 CPU초 / 목표 CPU 이용률
원시 전송 바이트 ≈ 월 점 수 × 점당 직렬화 바이트 + 배치 헤더
```

점당 100바이트를 가정하면 1,000명 시 월 약 2.16GB이지만, GPS 원본을 한 달 저장한다는 뜻은 아닙니다. 매칭 후 삭제 규칙을 적용합니다. JSON과 TLS·토큰·헤더·재시도 비용을 별도로 실측합니다.

구간별 통계도 무작정 저장하면 커집니다. 10만 구간을 매분 저장하면 하루 1.44억 행입니다. 따라서 PostgreSQL에는 노드·지도 목록과 제한된 시간별/평가 요약을 보관하고, 장기 분석이 필요한 공개 집계는 묶음 파일로 저장합니다. 빈 구간을 매분 행으로 생성하지 않습니다.

R2는 현재 인터넷 전송료가 없지만 저장·읽기·쓰기 비용은 있습니다. 최신 교통정보 파일을 모든 노드가 매초 읽게 하면 읽기 연산과 노드 다운로드가 늘어납니다. 조건부 조회, 변경 알림, 지역별 묶음, 캐시를 비교합니다. [R2 가격](https://developers.cloudflare.com/r2/pricing/)

## 단계별 예산 운영

| 단계 | 계획상 월 지출 상한 후보 | 상한으로 가능한지 확인할 항목 |
| --- | --- | --- |
| M0 | 로컬 장비 우선, 외부 유료 자원 없음 | 그래프 빌드·메모리·데이터 다운로드 |
| M1~M2 | $100 | 운영자 노드 2대, Cloudflare, 작은 DB, 저장소의 실제 견적 |
| M3 | $300 | 시험 참여 규모, 매칭 CPU, 지도 배포, DB 증가량 |

상한은 예산 제안이며 승인된 지출이나 견적이 아닙니다. 실제 공급자 가격과 성능을 확인해 조정합니다. 사용자가 정한 한도가 없다면 자동으로 유료 자원을 생성하지 않습니다.

매일 `기여 운전 1시간당 비용`, `경로 1,000건당 비용`, `유효 실시간 구간 1,000개당 비용`을 함께 봅니다. GPS 입력이 많아도 쓸 수 있는 구간이 적으면 그 비용을 숨기지 않습니다. 비용 급증 시 신규 수집을 제한하고, 이미 계산된 경로 안내와 기본 경로 조회를 우선 유지합니다.
