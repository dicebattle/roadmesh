# 제품 목표와 첫 출시 범위

## 만들 제품

RouteLens의 목표는 작은 운영 주체와 자원봉사자가 함께 운영할 수 있는 자동차 내비게이션 기반을 만드는 것입니다. 사용자에게는 경로와 그 경로의 예상 이동시간을 제공하고, 운영자에게는 자신의 서버에서 실행할 수 있는 경로 노드와 검증된 교통정보 배포 규격을 제공합니다.

출발점은 **수집·검증은 운영자가 책임지고, 경로 계산은 독립 서버들에 분산하는 구조**입니다. 완전한 탈중앙화나 운영비가 전혀 없는 서비스를 약속하지 않습니다. 독립 운영자들이 같은 규격으로 연결되는 형태를 먼저 만들고, 공개 P2P 전파는 이후 추가합니다.

## 첫 사용자를 어떻게 확보할 것인가

초기에는 한 도시의 한 생활권과 연결 간선도로를 시험 지역으로 정하고, 동의한 시험 운전자와 승인된 서버 운영자만 참여합니다. 지역은 데이터 품질·참여자 모집 가능성을 보고 M0에서 확정합니다. 표본이 충분하지 않은 지역에서도 기본 지도 기반 경로는 제공하지만 실시간 속도 개선 효과는 별도로 측정합니다.

주행정보 제공은 선택입니다. 기여하지 않는 사용자의 길찾기를 막지 않습니다. 포인트·토큰·가상화폐 보상은 초기 범위에 넣지 않습니다. 보상은 허위 관측을 만들어낼 유인을 키우므로 정확도와 악용 방지 검증 후 별도 결정합니다.

## 버전별 사용자 경험

| 단계 | 사용자가 할 수 있는 일 | 완료로 인정하지 않는 상태 |
| --- | --- | --- |
| M0 기술 검증 | 합성 경로와 허가된 기록을 재생해 계산 결과 비교 | 화면에 경로선만 나타남 |
| v0.1 개발자 미리보기 | 좌표로 경로 요청, 지도에서 결과·정보 나이 확인, 서버 두 대 사이 장애 전환 | 실제 운전용 앱이라고 홍보 |
| v0.2 제한된 Android 시험 | 동의 후 주행정보 기여, 회전 안내·음성·이탈 재탐색, 통신 끊김 표시 | 전국 서비스·상용 내비게이션 수준 주장 |
| v0.3 운영자 연합 | 독립 운영자가 노드를 설치하고 검증된 자료로 계산 | 아무 노드의 응답이나 신뢰 |
| v0.4 선택적 P2P | 공개 지도와 승인된 교통정보를 노드끼리 복제 | 원시 GPS나 경로 요청을 공개망에 전파 |

## v0.1에 포함할 것

1. 한 지역의 OSM 기반 도로 그래프를 재현 가능하게 생성하고 검증하는 작업.
2. Valhalla의 경로 계산과 지도 매칭을 연결하는 얇은 실행 프로그램.
3. 합성·허가된 관측의 수집, 중복 제거, 구간 통과시간 집계, 만료 처리.
4. 지도 버전과 결합된 교통정보 파일, 서명 검증, 원자적 버전 교체.
5. 운영자가 관리하는 기준 서버 한 대와 시험 서버 한 대. 동일 지역 전체를 각각 보유.
6. 요청의 지도·교통정보 버전에 맞는 서버 선택과 제한된 재시도.
7. MapLibre 웹 화면: 좌표 선택, 경로, 예상시간, 실시간 정보가 적용된 비율, 마지막 갱신 시각.
8. 로컬 설치 문서, 합성 입력, 호환성 검사, 개인정보 없는 관측 지표.

## v0.1에서 제외할 것

- 전국 장소·주소 검색, iOS, Android Auto, CarPlay, 차선 안내, 과속단속 안내.
- 휴대폰의 전국 오프라인 경로 계산. 통신이 끊기면 저장된 경로 안내만 유지하며 이탈 후 재계산 불가를 명시.
- 서로 다른 지역 서버가 경로 조각을 나눠 계산하는 방식. 경계에서 최적 경로와 회전 제약을 보장하기 어려움.
- 허가 없는 서버 참여, 분산 합의, 자체 P2P 통신 프로토콜 개발.
- 버스 관제와 배차 관리. 별도 제품 계획으로 유지.
- 기존 서비스의 운영 데이터 복사, 실주행 원본 공개, 외부 데이터의 무조건적인 재배포.

## 가장 먼저 확인할 위험

한국 OSM의 자동차 통행·회전 제한·고가도로/지하차도 구분 품질, 지도 매칭의 정확도, 교통정보를 넣었을 때의 실제 경로 변화가 첫 번째입니다. 이 세 가지가 해결되지 않으면 서버를 늘려도 올바른 내비게이션이 되지 않습니다.

작은 GPS 표본으로 전국의 실시간 교통상황을 추정하지 않습니다. 관측이 없는 도로는 `UNKNOWN`, 표본이 부족한 도로는 `INSUFFICIENT`, 오래된 결과는 `STALE`로 구분합니다. 상세 규칙은 [계약 초안](04-protocol.md)에 있습니다.
