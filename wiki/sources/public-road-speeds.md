## Actual access and limitations / 실제 접근과 한계

Existing locally configured ITS credentials permitted the actual read; no new account, subscription, key grant or secret publication occurred. Only credential names/presence were inspected, never printed values. Seoul API HTTPS attempts timed out; HTTPS for official file downloads succeeded. Node's trust chain rejected www.its.go.kr's supplied certificate chain; system curl verified it using its normal trust store and downloaded the official manual. TLS verification was not disabled. The manual says no current daily cap, with future caps possible; still use bounded regional polling and caching rather than unbounded requests.

기존 로컬 ITS 키로 읽었고 신규 계정·신청·권한 변경·키 공개는 하지 않았습니다. 서울 API의 현재 접속 실패와 파일 다운로드 성공을 구분합니다. ITS 웹 문서의 Node 인증서 체인 오류는 정상 시스템 신뢰 저장소의 curl로 확인했으며 인증서 검증을 끄지 않았습니다. 공식 안내가 현재 일일 제한 없음으로 적어도 지역별 제한 수집·캐시를 사용합니다.

## Decision and proof boundary / 결정·증거 경계

Start from the verified timestamped ITS numeric feed and official link geometry, retain source/revision/time/units, normalize to m/s, reject stale/future/invalid values, and map directed geometry conservatively onto the exact pinned Valhalla graph. Public agency data must bypass the crowd's five-contributor threshold through a distinct explicit public contract, never fabricated contributors or SYNTHETIC labeling. Reuse existing traffic-file encoding, native routing, signing/authorization and browser where their contracts can be honestly extended. Measure actual mapped/returned-route coverage rather than claiming nationwide completeness from a successful API response.

실제 확인한 시각 포함 ITS 속도와 공식 지형부터 연결하고 출처·버전·시각·단위를 보존합니다. 오래됨·미래·오류 값을 거부하고 정확한 엔진 지도에 방향까지 보수적으로 대응합니다. 공공 자료는 별도 명시 계약으로 쓰고 사용자5명·합성 출처를 위조하지 않습니다. 기존 변환·경로·서명/승인·화면을 정직하게 확장하며 실제 대응/반환 경로 적용률을 측정합니다.

## 2026-10-26 — Official compatible map layer / 공식 호환 지도 레이어

The official [WMS capabilities](https://its.go.kr:9443/geoserver/ntic/wms?service=WMS&request=GetCapabilities) advertise T_COB_MOCT_LINK_M and N_LEVEL_15. Actual bounded GetFeatureInfo returns exact `T_COB_MOCT_LINK_M.<link ID>` identities, F_NODE/T_NODE, road attributes and ordered LineString in EPSG:4326; N_LEVEL_15 supplies the same complete curve with link_id/road_name. These exact nodes match the numeric API where the downloaded national2026-10-14 and historical2025-10-14 do not. This is measured compatibility for acquired links, not universal equivalence or a dataset revision claim. Actual development checked34 midpoints, retained66 responses, verified18 links and31/79 graph edges;15 point reads failed, including XML service errors under HTTP200. Never treat200 as successful GeoJSON. Current code preserves failures/omissions and independent raw identities.

공식 기능 명세에 공개된 두 레이어를 제한 조회한 결과 수치 API와 같은 정확한 링크·방향 노드·전체 곡선을 확인했습니다. 2025/2026 전국 원본과 다른 번호를 자르는 대신 실제 제공자 지형을 별도로 검증합니다.34지점·66응답에서18링크·31/79구간을 확인했으며15지점은200의 오류 XML 등을 반환해 제외했습니다. 모든 도로의 동등성이나 전국 원본 버전 확인으로 확대하지 않습니다.

Archive metadata is read from the official [node/link archive](https://www.its.go.kr/nodelink/nodelinkRef) through its declared anonymous read endpoint. The2025-10-14 archive is DF_206/file1; actual relevant geometry and nodes are unchanged from2026-10-14, so historical download did not fix the problem. `/map/link/list` without a disaster-zone selector returned an empty list; it was not used to invent geometry. Large archives and source geometry remain local. The numeric portal's unrestricted reuse does not automatically settle separate map-layer redistribution terms; this implementation publishes code/provenance/coverage and OSM-based screenshots, not a wholesale government geometry mirror.

공식 과거 목록에서2025-10-14 자료를 실제 내려받아 비교했지만 문제는 해결되지 않았고 재난 도로 목록 조회도 빈 결과였습니다. 큰 원본·정부 지형은 로컬에 남기며 수치 API의 이용 조건을 별도 지도 레이어 전체 재배포 허가로 확대하지 않습니다.
